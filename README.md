# تجديد

نظام مبيعات ومخزون وعمولات لأدوات منزلية مستعملة. المرحلة 0 تجهّز الأساس: الواجهة العربية، وقاعدة البيانات، وقواعد الصلاحيات. تسجيل الدخول وإدارة المنتجات يجيئوا في المراحل التالية.

## تشغيل محلي

```bash
npm install
cp .env.example .env.local
npm run dev
```

التطبيق يفتح على المنفذ `3210`. صفحات الهيكل تعمل بدون سوبربيز. ربط المشروع الحقيقي محتاج القيم في `.env.local`، ومن غير لصق أي مفتاح في الشات.

```bash
npm run lint
npm run typecheck
npm test
npm run test:db
npm run seed:super-admin
```

`test:db` ينزّل المايجريشن على PostgreSQL محلي. `seed:super-admin` يسأل عن كلمة مرور المدير العام مرة واحدة ولا يخزّنها.

المواصفات الكاملة في `PRD.md` و`DATABASE.md` و`BUILD_PLAN.md`.
